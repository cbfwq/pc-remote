# 排查手册

## 一、手机打不开页面

按顺序排除：

1. **是否同一网络**：手机关掉移动数据（部分安卓机在 Wi-Fi 信号弱时会切到流量），确认连的是同一个 Wi-Fi；路由器开了「访客网络」的话，访客设备与主网络不通。
2. **服务是否在跑**：电脑上 `netstat -ano | grep 8765`，有 `LISTENING` 才算活着；没有就启动一次。
3. **地址是否过期**：打开 `遥控器地址.txt` 看最新一次写入的 IP 与时间。路由器重启、换 Wi-Fi、DHCP 重新分配都会换 IP。
4. **防火墙（最常见）**：
   - 路径：Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙 → 更改设置
   - 必须勾选 **`pythonw.exe`**（无窗口启动用的就是它）。之前只放行过 `python.exe` 的机器，换成 pythonw 后会重新被拦，且**不弹提示**，表现为手机一直转圈。
   - 手工加规则（需管理员）：`netsh advfirewall firewall add rule name="PC Remote" dir=in action=allow protocol=TCP localport=8765`
5. **服务只绑了 127.0.0.1**：`remote.py` 绑定的是 `0.0.0.0`，若被改过会导致仅本机可访问。

## 二、页面能开，按键没反应

先分清是"按键没发出去"还是"发了没人接"：

- 页面上按钮点击后右上角会显示"已发送"，说明请求到达了服务端，问题在**播放器不认这个键**。
- 显示"失败"或"连接断开"，说明服务端报错或掉线，看 `start.bat` 的控制台。

播放器键位对照（`*` 表示用页面上的 PageUp/PageDown 按钮）：

| 播放器 | 播放/暂停 | 上一集 / 下一集 | 快退/快进 | 备注 |
|---|---|---|---|---|
| 浏览器全屏视频（Chrome/Edge） | 多媒体键 ✅ | 多数网页播放器不支持，用 ◀◀ ▶▶ | 方向键 ✅ | 需视频处于播放状态、页面在前台 |
| PotPlayer | 多媒体键 ✅ | PageUp / PageDown，或 `[` `]` | 方向键 ✅ | 设置里可关掉全局多媒体键，关了就不认 |
| VLC | 多媒体键 ✅ | `N` / `P`（默认无快捷键，需自行绑） | 方向键 ✅ | 需勾选"允许键盘控制" |
| 迅雷影音 / QQ影音 | 多媒体键 ✅ | PageUp / PageDown | 方向键 ✅ | — |
| 电影和电视（Windows 自带） | 多媒体键 ✅ | 不支持 | 方向键 ✅ | — |
| 爱奇艺/腾讯视频/优酷客户端 | 不一定 | 不一定 | 方向键 | 这类客户端常自己接管热键，优先用触控板点 |

其它可能：

- **窗口焦点问题**：方向键、空格这类普通键只发给当前前台窗口。若播放器在后台，先按「切窗口」或点触控板把焦点切过去。
- **多媒体键被别的程序抢占**：同时开着网易云、QQ音乐时，媒体键可能被它们截走。关掉或退出系统托盘里的音乐软件。
- **设置了"仅本应用"热键**：部分播放器允许把全局热键改为局部，改回全局即可。

## 三、触控板光标不动或乱飘

- 光标乱飘：多数是鼠标传感器脏了（尤其无线鼠标），清理底部光学窗口；也可能是灵敏度问题，`remote.py` 页面里 `const SENS = 2.0;` 调小。
- 光标不动：窗口是否被 UAC 弹窗遮挡——Windows 默认禁止普通权限进程向管理员窗口发送输入（UIPI 机制）。以管理员身份运行 `remote.py` 可覆盖，或先关掉那个弹窗。
- 拖动失败：用「按住」按钮，点一次按下、再点一次松开。

## 四、语音不工作

- **手机浏览器点语音没反应、或立刻提示失败**：正常现象。Web Speech API 要求安全上下文（https 或 localhost），`http://192.168.x.x` 属于不安全来源，浏览器直接禁麦克风。页面会自动切到输入法输入框，这是设计好的降级路径。
- **想真正用浏览器识别**：需要 https。自签证书在手机上会报警告、且 Chrome 对证书错误页是否放行麦克风并不稳定，实际体验不如直接用输入法语音，一般不建议折腾。
- **输入法语音也不出字**：手机输入法要开启语音输入权限（设置 → 应用 → 输入法 → 麦克风）。
- **识别成文字后没打到电脑上**：确认电脑光标停在可输入的输入框里；部分全屏独占程序（部分游戏、某些播放器的全屏模式）会拒绝粘贴。

## 五、无窗口启动失败（双击 vbs 没反应）

1. **根本原因是 pythonw 下 print 崩溃**：`sys.stdout` 为 `None` 时 `print()` 抛 `AttributeError`。`remote.py` 顶部已有重定向，若被删掉会表现为「进程一闪即退、无任何提示」。
2. 用 `start.bat` 跑一次，看控制台报错——这是唯一能看到错误的方式。
3. 脚本找不到 Python 时，`start_hidden.vbs` 会弹 MsgBox 提示；若连 MsgBox 都没有，说明 vbs 没被执行（双击可能被记事本关联打开）。
4. 确认服务确实在跑：`netstat -ano | findstr 8765`。

## 六、开机自启没生效

- 检查启动文件夹里是否存在 `PC Remote.vbs`：
  `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`
- 该 vbs 里存的是**绝对路径**，安装目录被改名/移动后失效，重跑 `setup_autostart.py` 即可。
- 用 `.cmd` 版（`--mode cmd`）作为备选，兼容性最好，代价是登录时闪一下黑窗口。
- 任务管理器 → 启动 选项卡里，确认没有被「禁用」。
- 公司/学校电脑可能被组策略禁用启动文件夹，需改用计划任务（`schtasks /create /sc onlogon ...`，需管理员）。

## 七、安全与边界

- 服务无鉴权，同一局域网内任何设备都能发按键和打字。家里 Wi-Fi 可接受；办公室、酒店、公共网络建议用完就关（`stop.bat`）。
- 需要加保护时：在 `Handler.do_GET` 里校验 `?t=<token>` 并用 `secrets.token_urlsafe()` 生成，页面里带上同一 token。
- 不要用这类工具做「自动刷群消息、自动聊天」——违反平台规则，且与本工具定位无关。

## 八、验证技巧（给 agent 用）

- 无头浏览器截图查布局：

```bash
"<edge或chrome路径>" --headless=new --disable-gpu --hide-scrollbars \
  --window-size=520,950 --screenshot=shot.png "http://127.0.0.1:8765/#pad"
```

  注意：无头 Chrome/Edge 有约 500px 的最小窗宽，用 390 宽截图会被裁掉右侧，看起来像布局溢出——那只是假象，用 520 复测即可。

- 页面的 `#pad` 锚点会直接打开触控板标签，方便单独截图。
- 验证剪贴板写入（不惊动前台程序）：调用 `remote._set_clipboard_text('probe')`，再用 PowerShell `Get-Clipboard` 读回。
