手机遥控器 · 使用说明
=====================

一、准备
  1. 电脑上要有 Python（3.9 以上）。没有就去 python.org 下载安装，
     安装界面务必勾选 "Add Python to PATH"。
  2. 手机和电脑连同一个 Wi-Fi（同一个路由器）。

二、启动
  双击 start_hidden.vbs —— 不会有任何窗口跳出来，这是正常的。
  想看到运行状态和报错，改双击 start.bat，留一个黑窗口别关。

三、连接
  启动后，同目录会生成 遥控器地址.txt，里面有一行地址，例如：
      http://192.168.1.5:8765
  把这个地址输进手机浏览器打开即可。
  建议：在手机浏览器菜单里选「添加到主屏幕」，以后像 App 一样点开。

四、怎么操作
  · 按键页
      上一集 / 播放暂停 / 下一集、音量增减 / 静音、快退快进、
      全屏 / 退出全屏 / 停止 / 切换窗口
      底部一排：投影（Win+P）、无线投屏（Win+K）、手机投电脑（打开系统设置）
  · 触控板页
      单指滑动移动光标，轻点 = 左键，双指轻点 = 右键，
      双指上下滑 = 滚轮，「按住」按钮 = 拖拽文件/进度条
  · 语音
      点底部蓝色圆钮。手机上会弹出输入框，点输入法键盘上的麦克风说话，
      再点「发送」。说「暂停」「下一集」「上一集」「大点声」「静音」「全屏」
      会直接执行；说其它内容，会当作文字打到电脑当前光标处。
  · 标 * 的按钮
      给不认系统多媒体键的播放器用（PageUp / PageDown 换集）。

五、停止 / 开机自启
  · 停止：双击 stop.bat
  · 开机自动启动：在本文件夹打开命令行，运行
        python setup_autostart.py
    取消自启：
        python setup_autostart.py --remove
    注意：自启条目里记的是这个文件夹的绝对路径，文件夹别改名、别移动。

六、连不上怎么办
  1. 打开 遥控器地址.txt 看最新地址。路由器重启、换 Wi-Fi 后 IP 会变。
  2. 放行防火墙：
     Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙 → 更改设置
     → 找到 pythonw.exe，勾上「专用」。这一步最容易漏，且不会弹提示。
  3. 电脑别休眠：电源设置里把「睡眠」改成「从不」；笔记本合盖也要设成不休眠。
  4. 按键没反应但显示「已发送」：是播放器不认这个键，改用标 * 的按钮，
     或者用触控板直接点。
  5. 方向键/空格没反应：那是一般按键，只发给当前前台窗口，
     先用「切窗口」把播放器切到前面。

七、注意
  本工具在局域网内没有密码，同一 Wi-Fi 下的任何设备都能操作这台电脑。
  家里用没问题；办公室、酒店等公共网络下，用完请双击 stop.bat 关掉。
